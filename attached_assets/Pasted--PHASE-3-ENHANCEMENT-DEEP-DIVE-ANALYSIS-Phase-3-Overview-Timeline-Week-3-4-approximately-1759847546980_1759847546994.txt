Rule Name: no-console-in-api-routes

File Location: eslint-rules/no-console-in-api-routes.js

Rule Configuration:

// .eslintrc.json
{
  "rules": {
    "custom/no-console-in-api-routes": ["error", {
      "allowedPatterns": [
        "app/api/**/*.ts"  // Block console.* in all API routes
      ],
      "exceptions": [
        "middleware.ts"    // Allow in middleware (runs before logging)
      ],
      "allowedMethods": []  // No console methods allowed
    }]
  }
}
Error Message:

❌ console.* is not allowed in API routes.
Use logger.info(), logger.error(), logger.warn() instead.
Example:
  // ❌ Bad
  console.error('Error:', error)
  
  // ✅ Good
  logger.error({ error, userId, endpoint }, 'Error occurred')

Features:

✅ Configurable retry strategy:
Initial delay: 1000ms

✅ Retry policies per operation type:
Database queries: 3 retries, 1s→2s→4s

Usage Example:

  maxAttempts: 5,
  initialDelay: 1000,
  maxDelay: 32000
})

  return await externalApi.fetchData()
}, {
  onRetry: (attempt, delay) => {
    logger.warn({ attempt, delay }, 'Retrying operation')
  }
})
3. Fallback Strategies (Day 3 - 1 day)

File: lib/resilience/FallbackHandler.ts

Critical Features with Fallbacks:

Feature	Primary	Fallback
Keyword Data	SeRanking API	Cached data from DB
Email Sending	SendGrid	Retry queue + manual notification

Rank Tracking	Google Search API	Fallback to last known ranks
Location Detection	IP-API service	Default to user's saved location
Implementation:

class FallbackHandler {
  async withFallback<T>(
    primary: () => Promise<T>,
    fallback: () => Promise<T>,
    options: { cacheTTL?: number }
  ): Promise<T> {
    try {
      return await primary()
    } catch (error) {
      logger.warn({ error }, 'Primary operation failed, using fallback')
      return await fallback()
    }
  }
}
Usage Example:

const keywordData = await fallbackHandler.withFallback(
  // Primary: Fetch from SeRanking API
  async () => await seRankingApi.getKeywordData(keyword),
  
  // Fallback: Use cached data from database
  async () => await db.getCachedKeywordData(keyword),
  
  { cacheTTL: 3600 } // Cache for 1 hour
)
